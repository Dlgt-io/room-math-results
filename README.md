# Delegate Room Mathematics

A public home for mathematical results developed through collaboration in [Delegate](https://dlgt.io) rooms.

Each result package brings together its mathematical statements, manuscripts, formal proofs where available, reproducible computations, attribution, and verification evidence. The package states what was checked and what remains open.

## Results

See the [result index](results/README.md). The first package is [covering bounds and constructions related to Erdős Problem #271](results/erdos-271/README.md), shared as public review drafts with formal sources and verification evidence.

## Organization

Use one directory per project under `results/<project-id>/`. Keep the project overview, manuscript sources, proof sources, computations, and verification evidence together. Each project may choose the folders it needs.

A project overview should identify the originating room, contributors, exact result and version, references, reproduction commands, and the scope of its review. Keep earlier release manifests and evidence when publishing a new version.

## Verification and attribution

A successful proof build establishes a claim about the exact formal statements and environment checked. A project should separately describe its correspondence to an informal manuscript, mathematical review, and literature or novelty assessment.

Credit human contributors and record participating agents and their roles. Authorship, citation information, and licenses belong to each result package. Inclusion here does not imply peer review or a claim of priority.
