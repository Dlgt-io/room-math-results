# Contributing a result

Create a directory under `results/` with a stable, descriptive identifier. Submit additions and corrections through a pull request.

Include a project README with:

- The problem, precise result, current version, date, and status: for example, exploratory, draft manuscript, or released package.
- A reference to the originating Delegate room and a record of contributors and their roles. Record agent participation separately from the agreed author list.
- Manuscript and proof sources, references, and any computation needed to reproduce the result.
- Exact toolchain and dependency versions, commands, source checksums, and the relevant verification outputs.
- What was independently checked, by whom or by which process, and any remaining review questions or limitations.
- The applicable licenses for text, code, and data, with existing third-party notices preserved.

Publish material intended for public release. Exclude credentials, private room discussions, personal data, and unrelated operational logs. Keep evidence focused on the mathematical claims and reproducibility.

For an update, state what changed and preserve the previous version's manifests and evidence. Describe corrections openly. A formal proof check, informal mathematical review, and a novelty assessment should each have their own stated scope.

Keep paragraphs on one source line, with blank lines between paragraphs. Check relative links and reproduction instructions before submitting.
